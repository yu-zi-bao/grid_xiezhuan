## 执行流程详解

### 第一步：登录 4A 系统
1. 打开 Chrome 浏览器
2. 导航到 `https://4a.fjit.cmcc:30002/`
3. 处理 SSL 证书警告：
   - 点击"高级"按钮
   - 点击"继续前往 4a.fjit.cmcc（不安全）"
4. 点击"SIM KEY"标签
5. 填写手机号：`13850686599`
6. 点击"登录"
7. **手动完成 SIM KEY 认证**（约 10-15 秒）

### 第二步：导航到 IBOP-OA
1. 在首页找到"IBOP_OA"控件
2. 点击进入"中国移动客户关系管理系统"
3. 等待页面加载完成

### 第三步：携号转网申请查询
1. 点击"携号转网申请查询"链接
2. 设置查询条件：
   - 归属地市：龙岩
   - 归属区县：永定
   - 申请类型：所有
   - 申请状态：所有
   - 起始时间：当天 00:00:00
   - 截至时间：当前时间

### 第四步：导出申请查询数据
1. 点击"查询"按钮
2. 等待查询完成
3. 点击"导出"按钮
4. 等待导出弹窗
5. **等待 30 秒**后点击"刷新"
6. 重复直到提示"处理完成"
7. 点击下载链接
8. 点击"确认"关闭弹窗

### 第五步：打开下载文件
1. 等待文件下载完成
2. 使用 Excel 打开 `CocExportMnpindex-*.xls`
3. 验证数据完整性

### 第六步：携号转网号码查询
1. 点击"携号转网号码查询"链接
2. 设置查询条件：
   - 归属地市：龙岩
   - 起始时间：当月第一天
   - 截至时间：当天
3. 点击"查询"
4. 点击"导出"
5. 等待导出完成
6. 点击"确认"关闭弹窗

### 第七步：Excel 比对生成报告
1. Python 脚本自动读取两个 Excel 文件
2. 从文件 2 提取 E 列="中国移动"的 A 列号码
3. 在文件 1 中匹配 D 列（手机号码）
4. 将匹配的号码标红
5. 生成《当日携转查询清单.xlsx》保存到桌面

## 常见问题

### Q1: SSL 证书警告如何处理？
A: 首次运行时，点击"高级"按钮，然后点击"继续前往 4a.fjit.cmcc（不安全）"。浏览器会记住信任状态。

### Q2: SIM KEY 认证失败怎么办？
A: SIM KEY 认证需要用户手动完成。请确保 SIM 卡已插入并正确配置。

### Q3: 导出等待时间过长？
A: 导出处理需要 30-60 秒。请耐心等待，脚本会自动轮询检查状态。

### Q4: Excel 文件打不开？
A: 确保已安装 xlrd 和 openpyxl 库：`pip install xlrd openpyxl`

### Q5: 比对结果不正确？
A: 检查文件 2 的 E 列（携出方网络标识）是否为"中国移动"，文件 1 的 D 列（手机号码）是否正确。
